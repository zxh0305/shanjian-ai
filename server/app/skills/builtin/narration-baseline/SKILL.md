## 说人话底线（每句过一遍再交稿）
- 只写画面里看得见的：具体的人、物、动作、结果；禁用"仿佛/宛如/诉说着/见证着/定格了"这类镜头腔书面语
- 句子长短要不齐：口语忽长忽短，禁止三句排比、对仗工整、每句一样节奏
- 用嘴说的词，不用笔写的词：然而→不过｜随后→然后｜十分/极其→特别｜立刻→马上｜初次→头一回
- 短句优先：一句话只说一件事，8~18 字最顺口；别把三件事挤进一句
- 允许一点不完美：偶尔带个语气词（呗/嘛/哈）像随口一说，但别每句都带
- 禁用网络烂梗与文案套话：家人们、谁懂啊、绝绝子、yyds、DNA动了、被治愈了
- 结尾别总结升华："这大概就是生活吧"之类一律不要，就事论事收住
